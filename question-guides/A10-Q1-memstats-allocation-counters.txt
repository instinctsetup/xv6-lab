xv6 OS LAB - ASSIGNMENT 10, A10 Q1: memstats: allocation counters
================================================================

WHAT THE QUESTION ASKS
----------------------
Count total allocated and freed pages inside kalloc()/kfree(), and a memstats() syscall printing total allocated, total freed, currently allocated, and available physical pages.

HOW TO BUILD AND RUN
--------------------
Build and boot:   make qemu CPUS=1
At the xv6 shell: memtest

WHICH FILES TO OPEN / SHOW
--------------------------
kalloc.c (kpage_allocs/kpage_frees counters, skipped during boot init), sysproc.c (memstats)

EXPECTED OUTPUT
---------------
Counters rise by 10 after sbrk of 10 pages and the freed count catches up after release (verified: 1118/907/211, then 1128/917/211).

---------------------------

----- sysproc.c - sys_memstats() -----
// Assignment 10, Q1(b): display physical-memory statistics gathered by
// the kalloc()/kfree() counters in kalloc.c.
int
sys_memstats(void)
{
  int total_alloc = kpage_allocs;              // total allocated pages (cumulative)
  int total_free  = kpage_frees;               // total freed pages (cumulative)
  int current     = total_alloc - total_free;  // pages in use right now
  // frames managed by the page allocator: from end of kernel to PHYSTOP
  int total_frames = (PHYSTOP - V2P((uint)end)) / PGSIZE;
  int available    = kfree_pages();            // exact free-list length (kalloc.c)

  cprintf("memstats: total allocated pages = %d\n", total_alloc);
  cprintf("memstats: total freed pages = %d\n", total_free);
  cprintf("memstats: currently allocated pages = %d\n", current);
  cprintf("memstats: available physical memory pages = %d (of %d total frames)\n",
          available, total_frames);
  return 0;
}

----- memtest.c - complete test program -----
// Assignment 10, Q1(c): user program that exercises kalloc()/kfree()
// through sbrk() and shows the memstats() counters before, after
// allocation and after release.
#include "types.h"
#include "stat.h"
#include "user.h"

int
main(void)
{
  int npages = 10;
  char *p;
  int i;

  printf(1, "memtest: initial memory statistics\n");
  memstats();

  p = sbrk(npages * 4096);
  if(p == (char*)-1){
    printf(1, "memtest: sbrk failed\n");
    exit();
  }
  // touch every page so the kernel really allocates physical frames
  for(i = 0; i < npages; i++)
    p[i * 4096] = 1;

  printf(1, "memtest: allocated %d pages with sbrk()\n", npages);
  memstats();

  sbrk(-npages * 4096);
  printf(1, "memtest: released %d pages\n", npages);
  memstats();

  exit();
}

IN THE LAB: WHAT TO DO AND WHAT TO SHOW
---------------------------------------
Note why the counters only count when kmem.use_lock is set (boot frees must not count). Run memtest, screenshot both stats blocks.

HOW IT IS IMPLEMENTED
---------------------
Two counters in kalloc.c: kpage_allocs++ in kalloc() and kpage_frees++ in kfree(), but only once kmem.use_lock is set, so the boot-time page freeing is not counted. memstats() prints both, their difference, and the free-list length.
