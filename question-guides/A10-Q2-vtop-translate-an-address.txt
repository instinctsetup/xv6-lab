xv6 OS LAB - ASSIGNMENT 10, A10 Q2: vtop: translate an address
================================================================

WHAT THE QUESTION ASKS
----------------------
A vtop() syscall taking a virtual address, finding its PTE with walkpgdir(), and returning frame address plus offset; invalid or unmapped addresses must be reported, not crash.

HOW TO BUILD AND RUN
--------------------
Build and boot:   make qemu CPUS=1
At the xv6 shell: vttest

WHICH FILES TO OPEN / SHOW
--------------------------
vm.c (vtop), sysproc.c

EXPECTED OUTPUT
---------------
Valid addresses return physical addresses; an unmapped address is reported cleanly.

CODE (verbatim from the repo)
---------------------------

----- vm.c - vtop() -----
// ------------------------------------------------------------------
// Assignment 10, Q2(a)(b): translate a virtual address of the current
// process into its physical address using walkpgdir(). Returns -1 if
// the address has no valid, present page-table entry.
int
vtop(uint va)
{
  pte_t *pte;

  // locate the page-table entry without creating missing tables
  pte = walkpgdir(myproc()->pgdir, (void*)va, 0);
  if(pte == 0 || !(*pte & PTE_P))   // entry missing or page not present
    return -1;
  // physical frame address | page offset = complete physical address
  return (int)(PTE_ADDR(*pte) | (va & 0xFFF));
}

----- sysproc.c - sys_vtop() -----
// Assignment 10, Q2(a): syscall wrapper - arg is the virtual address.
int
sys_vtop(void)
{
  int va;
  if(argint(0, &va) < 0)
    return -1;
  return vtop((uint)va);
}

----- vttest.c - complete test program -----
// Assignment 10, Q2(c): user program that allocates memory with sbrk()
// and translates several virtual addresses to physical addresses with
// the vtop() system call, including an unmapped address.
#include "types.h"
#include "stat.h"
#include "user.h"

int
main(void)
{
  int npages = 4;
  char *p;
  int i;
  int addrs[3];
  int bad, pa;

  p = sbrk(npages * 4096);
  if(p == (char*)-1){
    printf(1, "vttest: sbrk failed\n");
    exit();
  }
  // touch the pages so they get real physical frames
  for(i = 0; i < npages; i++)
    p[i * 4096] = 1;

  printf(1, "vttest: translating virtual addresses of the sbrk() block\n");
  addrs[0] = (int)p;                 // start of block
  addrs[1] = (int)p + 4096;          // second page of block
  addrs[2] = (int)p + 2500;          // offset inside first page
  for(i = 0; i < 3; i++){
    pa = vtop(addrs[i]);
    if(pa < 0)
      printf(1, "vttest: va 0x%x -> not mapped\n", addrs[i]);
    else
      printf(1, "vttest: va 0x%x -> pa 0x%x\n", addrs[i], pa);
  }

  // invalid / unmapped virtual address (far above this process's memory)
  bad = 0x40000000;
  pa = vtop(bad);
  if(pa < 0)
    printf(1, "vttest: va 0x%x -> not mapped (vtop returned %d)\n", bad, pa);
  else
    printf(1, "vttest: va 0x%x -> pa 0x%x\n", bad, pa);

  exit();
}

IN THE LAB: WHAT TO DO AND WHAT TO SHOW
---------------------------------------
Compare with A8 Q1: same walk, quieter output. Run vttest, screenshot valid and invalid cases.

HOW IT IS IMPLEMENTED
---------------------
vtop(): the same walkpgdir lookup as va2pa without the printing - check the PTE exists and is present, then return PTE_ADDR(*pte) combined with the page offset; report invalid or unmapped addresses cleanly.
