xv6 OS LAB - ASSIGNMENT 10, A10 Q3: pageinfo and setreadonly
================================================================

WHAT THE QUESTION ASKS
----------------------
pageinfo() shows whether an address is mapped plus its frame and P/W/U flags; setreadonly() clears PTE_W on the page. Writing afterwards must fault.

HOW TO BUILD AND RUN
--------------------
Build and boot:   make qemu CPUS=1
At the xv6 shell: pagetest

WHICH FILES TO OPEN / SHOW
--------------------------
vm.c (pageinfo, setreadonly), sysproc.c

EXPECTED OUTPUT
---------------
The page shows writable, then read-only after setreadonly, and the attempted write faults and the process is killed.

CODE (verbatim from the repo)
---------------------------

----- vm.c - pageinfo() -----
// Assignment 10, Q3(a): report mapping, physical frame number and the
// page-table flags (P, W, U) for a virtual address of the current process.
int
pageinfo(uint va)
{
  pte_t *pte;

  pte = walkpgdir(myproc()->pgdir, (void*)va, 0);
  if(pte == 0 || !(*pte & PTE_P)){
    cprintf("pageinfo: virtual address 0x%x is not mapped\n", va);
    return -1;
  }
  cprintf("pageinfo: va 0x%x -> frame %d (pa 0x%x) flags:%s%s%s\n",
          va, PTE_ADDR(*pte) >> 12, PTE_ADDR(*pte) | (va & 0xFFF),
          (*pte & PTE_P) ? " P" : "",
          (*pte & PTE_W) ? " W" : "",
          (*pte & PTE_U) ? " U" : "");
  return 0;
}

----- vm.c - setreadonly() -----
// Assignment 10, Q3(b): remove write permission (PTE_W) from the
// page-table entry for a virtual address of the current process.
int
setreadonly(uint va)
{
  pte_t *pte;

  pte = walkpgdir(myproc()->pgdir, (void*)va, 0);
  if(pte == 0 || !(*pte & PTE_P))
    return -1;
  *pte &= ~PTE_W;                  // clear the writable bit
  lcr3(V2P(myproc()->pgdir));      // flush the TLB so the new permission applies
  return 0;
}

----- sysproc.c - sys_pageinfo() -----
// Assignment 10, Q3(a): syscall wrapper - arg is the virtual address.
int
sys_pageinfo(void)
{
  int va;
  if(argint(0, &va) < 0)
    return -1;
  return pageinfo((uint)va);
}

----- sysproc.c - sys_setreadonly() -----
// Assignment 10, Q3(b): syscall wrapper - arg is the virtual address.
int
sys_setreadonly(void)
{
  int va;
  if(argint(0, &va) < 0)
    return -1;
  return setreadonly((uint)va);
}

----- pagetest.c - complete test program -----
// Assignment 10, Q3(c): user program that allocates a page, shows its
// page-table information with pageinfo(), removes write permission with
// setreadonly(), and then writes to the protected page to demonstrate
// that a page fault occurs.
#include "types.h"
#include "stat.h"
#include "user.h"

int
main(void)
{
  char *p;

  p = sbrk(4096);
  if(p == (char*)-1){
    printf(1, "pagetest: sbrk failed\n");
    exit();
  }
  p[0] = 42;  // touch the page so it gets a physical frame

  printf(1, "pagetest: page allocated at va 0x%x\n", (uint)p);
  pageinfo((int)p);

  printf(1, "pagetest: removing write permission with setreadonly()\n");
  if(setreadonly((int)p) < 0){
    printf(1, "pagetest: setreadonly failed\n");
    exit();
  }
  pageinfo((int)p);

  printf(1, "pagetest: attempting to write to the read-only page...\n");
  p[0] = 99;  // must trigger a page fault (trap 14) and kill this process
  printf(1, "pagetest: ERROR - write to read-only page succeeded\n");
  exit();
}

IN THE LAB: WHAT TO DO AND WHAT TO SHOW
---------------------------------------
Find where the fault lands in trap.c and why the process is killed rather than the page silently re-writable. Run pagetest, screenshot.

HOW IT IS IMPLEMENTED
---------------------
pageinfo(): walk to the PTE and print the frame and P/W/U flags. setreadonly(): walk to the same entry and clear PTE_W. The next write faults because the hardware checks that bit on every store; the fault handler kills the process.
