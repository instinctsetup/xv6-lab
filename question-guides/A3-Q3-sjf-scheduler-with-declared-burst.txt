xv6 OS LAB - ASSIGNMENT 3, A3 Q3: SJF scheduler with declared burst
================================================================

WHAT THE QUESTION ASKS
----------------------
A burst_time field and a set_burst() syscall so a process declares its expected length; the scheduler picks the smallest burst, non-preemptive; processes that never set a burst go last.

HOW TO BUILD AND RUN
--------------------
Build and boot:   make clean && make SCHED=SJF qemu CPUS=1
At the xv6 shell: sjftest

WHICH FILES TO OPEN / SHOW
--------------------------
proc.c (SJF case in key()), sysproc.c (set_burst), proc.h (burst_time)

EXPECTED OUTPUT
---------------
Completion in ascending burst order (verified: burst 20, 40, 60).

---------------------------

// ---- Assignment 3 Q3 / Assignment 4: set_burst(int pid, int bt) ----
int
sys_set_burst(void)
{
  int pid, bt;
  if(argint(0, &pid) < 0 || argint(1, &bt) < 0 || bt <= 0)
    return -1;
  return set_proc_field(pid, bt, 0);
}

----- sjftest.c - complete test program -----
// Assignment 3, Question 3 test: SJF (shortest job first, estimated burst).
// Build and run with: make qemu SCHED=SJF CPUS=1
// The parent declares each child's burst by pid while the children sleep,
// so all three jobs are runnable with known bursts before any runs.
// Expected: completion order is short(20), medium(40), long(60) even
// though the long job was created first.
#include "types.h"
#include "stat.h"
#include "user.h"
#include "pinfo.h"

static void work(int me, int burst)
{
  volatile int i, x = 0;
  sleep(20);                     // let the parent declare all bursts first
  for(i = 0; i < burst * 1000000; i++) x += i;
  struct pinfo pi;
  getpinfo(&pi);
  printf(1, "sjf: child %d done (burst %d, rtime %d)\n", me, burst, pi.rtime);
  exit();
}

int
main(void)
{
  int p0, p1, p2;
  if((p0 = fork()) == 0) work(0, 60);   // long, created first
  set_burst(p0, 60);
  if((p1 = fork()) == 0) work(1, 20);   // short
  set_burst(p1, 20);
  if((p2 = fork()) == 0) work(2, 40);   // medium
  set_burst(p2, 40);
  wait(); wait(); wait();
  printf(1, "sjf: test complete\n");
  exit();
}

IN THE LAB: WHAT TO DO AND WHAT TO SHOW
---------------------------------------
Check how key() maps an unset burst (-1) to the largest key so it schedules last. Run sjftest, screenshot.

HOW IT IS IMPLEMENTED
---------------------
Add burst_time to proc.h and wire set_burst the same way as set_priority. The scheduler picks the smallest declared burst and never preempts; map an unset burst to the largest key so those processes go last.
