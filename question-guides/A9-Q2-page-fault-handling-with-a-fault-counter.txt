xv6 OS LAB - ASSIGNMENT 9, A9 Q2: Page fault handling with a fault counter
================================================================

WHAT THE QUESTION ASKS
----------------------
The lazy-allocation sheet's version: sbrk only records growth, T_PGFLT allocates on demand, a new pgfaults field counts handled faults, and getfaults() returns it. Touching 5 pages after sbrk(32 * 4096) must report exactly 5 faults.

HOW TO BUILD AND RUN
--------------------
Build and boot:   make clean && make LAZY=1 qemu CPUS=1
At the xv6 shell: faulttest

WHICH FILES TO OPEN / SHOW
--------------------------
Shared lazy handler with A8 Q4; proc.h (pgfaults), sysproc.c (getfaults)

EXPECTED OUTPUT
---------------
faults = 5 after 5 touches, re-touching a mapped page adds none, and an access above sz kills only the child while the parent survives (verified).

CODE (verbatim from the repo)
---------------------------

----- trap.c - shared lazy page-fault handler (A8 Q4) -----
  case T_PGFLT:
    // Assignment 8 Q4 / Assignment 9 Q2: lazy allocation. sbrk() (see
    // sysproc.c) only records the new size; the first touch of each page
    // faults here and gets a frame on demand. This covers BOTH user-mode
    // touches and kernel-mode touches (a syscall copying to/from a lazy
    // user buffer) - the faulting address is what matters, not the mode.
    {
      struct proc *p = myproc();
      uint va;
      char *mem;
      if(p == 0)
        goto lazy_fail;
      va = rcr2();
      if(va < p->heap_start || va >= p->sz || uvmpresent(p->pgdir, va))
        goto lazy_fail;              // outside the recorded heap: real fault
      mem = kalloc();
      if(mem == 0){
        cprintf("lazyalloc: out of memory\n");
        goto lazy_fail;
      }
      memset(mem, 0, PGSIZE);
      if(mappages(p->pgdir, (char*)PGROUNDDOWN(va), PGSIZE, V2P(mem),
                  PTE_W|PTE_U) < 0){
        kfree(mem);
        goto lazy_fail;
      }
      p->pgfaults++;                 // A9 Q2: counted for getfaults()
      break;
    lazy_fail:
      if((tf->cs&3) == 0)
        panic("lazyalloc: kernel page fault outside user heap");
      cprintf("pid %d %s: unhandled page fault at 0x%x\n",
              p ? p->pid : 0, p ? p->name : "?", rcr2());
      if(p)
        p->killed = 1;
    }
    break;
#endif

----- sysproc.c - sys_getfaults() -----
// ---- Assignment 9 Q2: lazy-allocation fault counter ----
int
sys_getfaults(void)
{
  return (int)myproc()->pgfaults;
}

----- faulttest.c - complete test program -----
// Assignment 9 Q2: test program for lazy allocation.
#include "types.h"
#include "stat.h"
#include "user.h"

#define PG 4096

int
main(int argc, char *argv[])
{
  char *p;
  int i, pid, f0, faults;
  int pages[5] = {0, 3, 7, 12, 31};

  f0 = getfaults();
  p = sbrk(32 * PG);   // lazy: nothing is allocated yet
  printf(1, "sbrk(32 * 4096) returned 0x%x, faults so far: %d\n", p, getfaults() - f0);

  for(i = 0; i < 5; i++)
    p[pages[i] * PG] = 'x';   // first touch of 5 distinct pages

  faults = getfaults() - f0;
  printf(1, "touched 5 pages, page faults handled: %d\n", faults);
  if(faults == 5)
    printf(1, "PASS: result is 5\n");
  else
    printf(1, "FAIL: expected 5\n");

  // Touch a page again: already mapped, no new fault.
  p[0] = 'y';
  printf(1, "re-touch of mapped page, total faults: %d\n", getfaults() - f0);

  // Access beyond the allocated size: only that process must die.
  printf(1, "child will now access address above its size...\n");
  pid = fork();
  if(pid == 0){
    p[40 * PG] = 'z';   // 32 pages were allocated, page 40 is invalid
    printf(1, "FAIL: child survived an invalid access\n");
    exit();
  }
  wait();
  printf(1, "parent still alive after child was killed: PASS\n");
  exit();
}

IN THE LAB: WHAT TO DO AND WHAT TO SHOW
---------------------------------------
Explain why the second touch is free (uvmpresent check). Run faulttest, screenshot the PASS lines.

HOW IT IS IMPLEMENTED
---------------------
Same lazy handler as A8 Q4, plus accounting: add pgfaults to struct proc, increment it in the T_PGFLT handler after a successful mapping, and wire a getfaults() syscall that returns it.
